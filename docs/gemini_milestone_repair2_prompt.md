# CampusMate 추가 수정 요청

`docs/codex_milestone_repair_review_20260924.md`를 읽고 R1~R4를 수정해줘. 이전 수정 중 정상 동작하는 기능은 유지하고 전체 완수로 보고하지 마.

1. 최우선: ScheduleEditModal에서 UTC 문자열을 서울 시각으로 잘못 재해석하는 문제와 초·소수점 초 유실을 해결해. 제목/우선순위만 수정하면 기존 시간 필드는 PATCH에서 제외해. 실제 시각을 수정할 때도 서울 기준 해석과 날짜 경계를 보장해.
2. 추출기의 특수 분기까지 모두 공통 달력·시각 검증을 적용해. 보고서 R2의 다섯 입력을 포함해 원문에 없는 날짜/업무 제목 생성, 명시 연도 무시, 1시간 계산의 분 손실과 날짜 넘김을 해결해. 특정 반례에만 맞춘 분기를 추가하지 마.
3. 출처 카드의 일정 추출에는 내부 문서의 실제 본문을 전달해. 본문을 확보할 수 없으면 사용자에게 본문 입력을 요청하고 제목/게시일만으로 일정을 만들지 마.
4. 브라우저 테스트가 실제로 후보 2의 제목/일시, 기간 중간 날짜 클릭, 51건 이상, 서울 자정 경계, 제목 수정 후 기존 시각 불변, 로그아웃 후 이전 토큰 401, 취소/미선택 시 미저장을 검증하도록 보강해. API 통합 테스트와 mock RAG 사용 여부를 정확히 표시해.

기존 147개 회귀와 빌드를 유지해. 테스트 기대값을 잘못된 구현에 맞추지 마. extra=forbid, confirmed, BOLA, 원자적 PATCH와 시간 정밀도 계약을 약화하지 마.

임시 DB로 검증하고 저장소 data 파일 해시를 전후 대조해. 외부 LLM/크롤링/배포/커밋/푸시는 하지 마. 결과를 `docs/gemini_milestone_repair2_report.md`에 실제 실행 명령, 결과, 해결/미해결, 제한 사항으로 나눠 기록해. 9개 파일 선택 실행을 저장소 전체 테스트라고 쓰지 마. 운영 알림의 범위 변경과 연기는 제안 상태로 명시해.

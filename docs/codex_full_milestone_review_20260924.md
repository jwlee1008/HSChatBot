```text

GET /api/v1/schedules: total=0
```

### F3 — P1: 게스트 계정의 공통 비밀번호 및 로그아웃 세션 미폐기

- 위치: `frontend-web/src/App.tsx:796`, `:1295`, `:1328`.
- 게스트 생성 두 경로가 모두 공개 프론트엔드에 있는 고정 비밀번호 `Password123!`를 사용한다. 게스트 사용자명을 아는 경우 공유 비밀번호로 인증할 수 있는 구조다. 사용자명 열거 가능성이나 실제 타인 계정 침해까지 검증했다는 뜻은 아니다.

- 자동 게스트 계정 생성을 제거하고 기존 회원가입/로그인으로 연결하거나, 별도 검토된 서버 측 익명 세션 설계가 필요하다. 로그아웃은 기존 서버 세션 폐기 API와 연결해야 한다.

### F4 — P1: 기준 날짜가 고정되고 미확정 정보가 자동 보충됨

- 원문 기반 확정값과 사용자가 직접 입력한 값을 구분하고, 필수값이 미확정이면 입력 전 저장을 막아야 한다.

## 왜 145개가 통과했는가

`tests/test_ui_and_e2e_flow.py`는 FastAPI TestClient로 올바른 payload를 직접 만든다. React 모달이 실제로 보내는 잘못된 payload를 사용하지 않는다. 정적 검사도 루트 HTML 확인이며 브라우저 클릭이나 후보 선택을 실행하지 않는다. API 통합 테스트로는 유효하지만 브라우저 E2E로 명명하고 사용자 흐름 완료의 증거로 쓰면 안 된다.

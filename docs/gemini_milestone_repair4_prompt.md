# CampusMate repair4 — 연도 보정 회귀만 수정

`docs/codex_milestone_repair3_review_20260925.md`를 읽고 남은 연도 처리 결함만 수정해줘. B/C 해결과 기존 공통 날짜·시각 검증은 유지해.

- `_validate_and_normalize_candidates`에서 문서/인용문 첫 연도를 모든 날짜 문자열에 치환하는 로직을 제거해.
- 시작/종료 각각에 명시된 연도를 보존해. '오늘/내일'은 reference_time 기준으로 계산하고 무관한 사업 연도를 적용하지 마.
- 연도 누락 추론이 필요하면 해당 날짜 표현과 문맥에서 수행해. 단순 전역 치환으로 해결하지 마.
- 공통 게이트는 유효한 원문 값을 그대로 보존하고 달력·시각·기간 순서 오류만 정확히 유보하도록 유지해.

검수 보고서의 네 입력을 독립 회귀 테스트로 추가해. 2025→2026, 2026→2027 양쪽 기간, 무관한 과거/미래 사업 연도와 오늘/내일, 기존 취소·다회차의 명시 연도 보존을 검증해. 기대값을 잘못된 구현에 맞추지 마.

기존 149개 회귀와 브라우저 E2E, 빌드, RAG 로컬 근거 검증을 유지해. 임시 DB 및 data 전후 파일 해시를 사용해. 외부 LLM/크롤링/배포/커밋/푸시는 하지 마.

완료 후 `docs/gemini_milestone_repair4_report.md`에 수정 내용, 반례별 실제 결과, 실행 명령/결과, 남은 제한을 기록해. 정상화한 UI/인증/저장 기능은 다시 전면 작성하지 마.

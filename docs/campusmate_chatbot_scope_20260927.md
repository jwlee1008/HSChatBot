# CampusMate 챗봇 현재 범위

2026-09-27 사용자 결정으로 제품 범위를 한성대학교 공식 공지 및 학사 안내 질의응답으로 한정한다. 이전 개선 계획의 로그인·개인 일정·캘린더·마감 알림은 활성 계획에서 제외한다.

## 활성 기능

- 로그인 없이 질문 입력, RAG 답변과 공식 원문 링크·게시일 카드 표시
- Chroma 기반 근거 검색, 설정된 생성 모델 연동, 근거 부족·API 오류 안내
- 기존 공지/첨부 처리와 날짜 정규화 개선 유지
- React 정적 화면과 FastAPI의 /health, /api/query, /api/retrieve

## 제외 및 보관

개인 일정 관련 소스와 검사는 archived_features/personal_schedule_20260927에 보관한다. 기본 앱은 해당 모듈을 import하지 않고 계정 SQLite를 생성하지 않는다. data/의 기존 파일 및 기존 Docker 개인 DB 볼륨은 삭제하지 않는다.

## 검증과 배포의 구분

현재 작업은 로컬 코드 분리 및 PRD 개정이다. Cloudtype의 기존 배포를 갱신하거나 AWS 자원을 생성하지 않았다. 챗봇 실 API 품질·메모리·응답시간과 선택한 환경에서의 배포 검증은 후속 작업이다. 과거 일정 테스트 수를 챗봇 품질 지표로 사용하지 않는다.

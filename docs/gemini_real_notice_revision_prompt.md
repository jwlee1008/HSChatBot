# 실제 공지 지원 수정 요청 — N1~N3

`docs/codex_real_notice_acceptance_review_20260925.md`를 읽고 N1~N3만 수정해줘. 실제 공지 목표 5/5와 이전 repair4 개선을 유지해.

1. N1: 새 점/슬래시 추출 경로의 잘못된 시작 시각을 날짜로 바꾸어 정상화하지 마. 시각 누락과 오류를 구분하고 시작/종료 각각의 24:00·25:00·23:90을 명시적으로 유보해. 검증 전 원문 정보를 잃지 않게 해.
2. N2: 기간 후보가 있어도 같은 문서의 단일 일정은 처리해. 이미 처리한 원문 구간만 제외하고, 접수 기간+면접 일시 변형과 실제 TOPCIT 4단계 시험 날짜/시간을 함께 회수해. 시험 9:30~12:00과 입실완료 9:10을 혼동하지 마. 종료 미명시 일정의 종료를 만들어내지 마.
3. N3: 실제 출처 카드 제목과 본문을 함께 비교할 수 있도록 계약을 연결해. 기존 클라이언트 호환과 extra=forbid를 유지해. 연도를 월/일로 잘못 읽는 제목 정규식을 수정하고 동일 날짜는 경고하지 않게 해. 실제 멘토링 문서의 별도 제목/본문 충돌을 브라우저에서 확인해. 근거 문자열의 원문 관계를 보존해.

기존 152개 핵심 회귀, 목표 공지 5/5, 빌드 및 RAG 근거 검증을 유지해. 추가 후보를 수동으로 대조하고 정확한 제목·시각·누락 여부도 테스트해. 목표값을 약화하거나 특정 문서별 정답을 넣지 마. 실제 출처 카드 → 추출 → 사용자 확인 흐름에서 제목 충돌 표시와 미선택 미저장을 확인해.

임시 DB, data 전후 파일 해시를 사용해. 외부 LLM/크롤링/배포/커밋/푸시는 하지 마. 완료 후 `docs/gemini_real_notice_revision_report.md`에 N1~N3별 수정과 실행 결과, 제한 사항을 기록해. 5/5 최소 회수를 전체 후보의 정확도 100%로 표현하지 마.

# CampusMate 챗봇 현재 산출물

기준일 2026년 10월 7일. 제품명은 CampusMate, 팀명은 저학년의 반란이다. 현재 제출·발표·개발 계획에는 아래 개정본을 사용한다.

로그인 없이 한성대학교 공식 공지·학사 안내를 질문하고 답변과 원문 출처를 확인하는 챗봇이다. 각 질문은 독립적으로 처리한다. 개인 일정·인증·캘린더·마감 알림은 보관 기능이다.

## 모든 산출물에 적용한 기준

- 현재 코드와 데이터 실적: 통합 1,366문서, 3,447청크, 제목만 확보한 공지 202건, 9월 15일 자료 스냅샷.
- 10월 7일 선별 오프라인 회귀 검사: 5개 파일 65 passed, 1 warning. 실제 LLM 답변 정확도와 구분한다.
- 생성은 Gemini API, 검색 임베딩은 서버의 ko-sroberta, 저장소는 ChromaDB, 웹은 React·TypeScript와 FastAPI다.
- 현재 로컬 모델 설정은 gemini-3.8-flash이며, 실제 API 성공·계정 한도 및 배포 환경변수는 후속 확인 사항이다.
- 대표 30~50질문 평가, 근거 지지 답변 90% 이상, 사용자 10명 이상, 만족도 4.0/5 이상은 달성 전 목표다.
- 최신판 배포와 학생 사용자 테스트는 미완료다. Cloudtype 무료 환경은 실제 자원 검증 후 판단한다.
- 제출 기한과 실명별 담당은 새로 확정하지 않았다. WBS에서 팀이 담당 역할·예정일·상태를 갱신한다.

## 이전 자료

루트의 9월 19일 PRD·WBS, 기존 CampusRAG 발표자료·계획서·마일스톤, 9월 27일 PRD v1.1은 이전 버전으로 보존한다. 이전 자료에 남은 로그인·일정·캘린더·알림과 과거 완료 비율을 현재 제출 기준으로 사용하지 않는다. 기능흐름도는 이미 현재 범위와 일치해 원본 내용을 유지했다.

기존 발표 대본은 `archived_artifacts/planning_before_20261007/`에 보존하고 루트의 대본 파일들은 현재 대본으로 갱신했다.

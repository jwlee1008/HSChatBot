## 1. 게시일이 같은 정정본이 여전히 기각됨 (P1)

`scripts/build_unified_dataset.py:50`은 date를 last_checked_at보다 먼저 선택하고
시각을 10자로 잘라 날짜만 비교한다. 게시일이 유지되는 일반적인 공지 수정에서
확인 시각 변화가 무시된다.

재현: 두 문서 date=2026-09-01, 기존 확인일=9/14, 신규 확인일=9/15.
본문을 긴 '9월 20일 마감'에서 짧은 '9월 15일 마감'으로 정정했으나,
missing_notices_refreshed가 notice_archive보다 우선이라는 이유로 기존 본문을 채택했다.

게시일·원문 수정일·확인 시각을 별도 의미로 처리하고, 같은 게시일의 정상 재수집
변경과 같은 날 시각 차이를 검증하라. 확인 시각을 원문 수정일로 표기하거나
최신 HTML에 이전 첨부 버전을 무조건 결합하지 마라. 원문 수정일이 확인 시각보다
강한 근거인 경우, 시간대 차이와 부분 실패 보존도 회귀 검사하라.

## 2. 요청하지 않은 기존 경로 삭제/재사용 옵션 (P1)

것만 확인했다. 실제 삭제는 실행하지 않았다.

기존 요청대로 두 옵션을 제거하고 **새 경로만** 허용하라. 빈 기존 디렉터리도
기본적으로 거부하고, 심볼릭 링크 및 기존 파일/DB 보존을 검사하라.

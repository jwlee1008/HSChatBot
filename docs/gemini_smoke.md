# Gemini 실제 연결 및 RAG 점검 (2026-09-15)

모델은 `.env`의 `gemini-3.8-flash`, 검색 데이터는 기존 데모 DB 복사본
(`campus_notices`, 217청크)이다. 최근 확장 수집한 공지/상시 안내를 합친 DB가 아니다.
운영 DB를 열거나 수정하지 않았고, 임시 복사본은 실행 후 정리했다.

## 실행 결과

단순 연결 요청은 “연결 성공”으로 응답했다. 첫 RAG 요청은 503 서버 혼잡으로
실패하여 별도 파일에 보존했고, 한 번 재시도한 뒤 이미 시도한 질문은 제외하여
남은 질문을 실행했다. 자동 재시도는 비활성화했다.

8개 질문 중 6개는 서비스 응답 완료, 2개는 API 503 오류였다.
응답 완료 6개 중 실제 Gemini 생성은 4개, LLM 호출 전 유보는 2개이다.
이는 정답률 75%나 전체 평가셋 성능을 의미하지 않는다.

| 질문 | 관측 결과 | 판단 |
| --- | --- | --- |
| CPA·세무사 장학금 대상 | 둘 다 포함된다고 답변. 검색 근거에 둘 다 명시 | 이번 실행에서 기존 반대 답변 문제 재현 안 됨 |
| 취업멘토링 신청 기간 | 제목의 상충 날짜를 지적하고 세부 일정 확인 불가 안내 | 실제 마감일 답변 실패. 검색된 두 청크에 신청 기간 본문 없음 |
| 기숙사 통금 시간 | 관련 공지를 찾지 못했다고 유보, 출처 없음 | 무관 채용 공지가 검색됐지만 답변에 끌어오지 않음 |
| TOPCIT 연장 마감 | API 503 | 답변 품질 미검증 |
| 편입생 신청 대상 | 부득이한 사유 등 설명, 외국인 유학생 제외 조건 누락 | 미해결. 검색된 두 청크에 제외 조건 없음 |
| 국가장학금 두 마감일 | title_only 안내로 조기 유보 | Gemini 미호출. 기존 데모 DB의 본문 미확보 문제 |
| TOPCIT 평가 | API 503 | 답변 품질 미검증 |
| 파이썬 코드 요청 | 관련 공지 없음으로 즉시 유보 | 검색 가드레일, Gemini 미호출 |

대상/일정 비교는 저장된 실제 검색 청크와 기존 `multidomain_audit.md`의 근거를
참고한 점검이다. 이번에 학교 원문을 다시 전수 수집하거나 20문항 전체를 평가하지 않았다.
완료된 Gemini 생성 4건의 검색 포함 시간은 약 3.6~8.9초이며 작은 표본으로
지연 목표 충족을 판단하지 않는다. 503 실패 시간도 위 범위에 포함하지 않았다.

## 코드 변경 및 검사

- `scripts/run_eval.py`가 `LLM_PROVIDER=local`로 강제 변경하던 코드를 제거했다.
- 평가 메타데이터에 실제 provider와 해당 provider의 모델명을 기록한다.
- `tests/test_evaluator.py`: provider 보존 회귀 검사 포함 **10 passed**.
- `scripts/smoke_gemini.py`: 복사한 데모 DB에 실제 RAG를 실행하고 응답/검색 근거를 저장한다.
  `--resume`은 같은 모델/DB 해시일 때 이미 시도한 ID를 건너뛰며 실패 ID도 자동 반복하지 않는다.

```bash
.venv/bin/python scripts/smoke_gemini.py
.venv/bin/python scripts/smoke_gemini.py --resume
.venv/bin/python -m pytest tests/test_evaluator.py -q
```

결과: `data/gemini_smoke_results.json`, 첫 실패: `data/gemini_smoke_initial_error.json`.
키와 모델 응답의 내부 서명은 결과 파일에 저장하지 않는다.

## 다음 우선순위

1. 필요한 일정/대상 조건 청크가 답변 문맥에 들어오도록 검색 결과 확장 방식을 개선한다.
2. 수집·OCR 보강 데이터를 통합한 별도 DB에서 다시 평가한다.
3. 서비스의 503/429 대응, 제한된 재시도와 사용자 오류 안내를 검증한다.
4. 이후 동일 데이터·질문 조건으로 로컬/Gemini 전체 평가를 비교한다.

Gemini의 생성 개선 가능성은 확인했지만, 모델 교체만으로 검색·데이터 누락이
해결되지는 않았다. 이번 단계에는 HTTP/브라우저 E2E, 배포가 포함되지 않는다.

# CampusMate 추가 수정 — 남은 세 결함만 처리

`docs/codex_milestone_repair2_review_20260925.md`를 읽고 A/B/C를 수정해줘. 기존 정상 동작은 유지하고 새 기능을 확장하지 마.

1. A: 추출기의 모든 후보 반환 경로를 공통 검증으로 통합해. 취소/선착순/반복/기간/휴업일/연장 등도 빠짐없이 실제 달력 날짜·시각·순서·명시 연도를 검증해. 오류값은 확정 날짜 필드에 남기지 말고 명시적으로 유보해. 정상 원문 값도 바꾸면 안 돼.
2. B: 원문에 없는 17:30/15:00과 특정 업무명 기본값을 제거해. 시각 미명시는 날짜 전용 또는 미확정으로 표현해. 단순 source_quote 부분문자열 검사 외에 후보 값이 그 근거에서 도출되는지 검증해.
3. C: 편집에서 시작/종료를 별도로 변경 추적해. 종료만 바꾸면 시작 원본 UTC 문자열과 초·마이크로초는 보존하고 반대 경우도 보장해. 유형 변경 시 필요한 필드 정리는 별도로 처리해.

보고서의 구체적 반례와 각 추출 분기의 정상/비정상/누락 입력을 회귀화해. 한 반례마다 특수 분기를 추가하는 방식은 금지야. 브라우저로 시작만/종료만/제목만 수정 후 미수정 필드가 바이트 단위로 같은지 검증해.

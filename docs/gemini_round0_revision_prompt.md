# Gemini R0 수정 라운드 — R1 착수 전

CampusMate R0를 Codex가 검수했다. 지정 회귀 54개는 통과했지만 평가 정답 오류와 정책 불일치가 있어 R0는 아직 통과하지 않았다. 이번에는 아래 수정만 수행한다.

1. `docs/codex_round0_review.md`의 실제 재현과 근거를 읽고 1~4번을 수정하라. 사용자 기존 변경과 데이터를 보존하고, 시작 시 git status를 확인하라.
2. RAG 대표 10사례를 `data/unified_campus_knowledge.json`과 다시 대조하라. TOPCIT 보증금/응시료를 구분하고 졸업유예 근거 URL과 자격을 바로잡아라. 각 정답 주장에 실제 문서 ID, URL, 정확한 근거 발췌, 입력 데이터 SHA-256을 기록하라. 확인되지 않은 규정·수정 이력을 추측하지 마라. 불확실한 OCR 숫자는 미확정 또는 추가 검수 필요로 기록하라. 새 크롤링은 필요 없다.
3. 모든 일정 후보의 저장 전 사용자 확인을 필수로 하라. `requires_user_confirmation`과 모호성 유무를 분리하라. 후보가 없는 사례는 확인 불필요로 둘 수 있다. sched-20의 모호한 자정 시각을 확정 timestamp로 만들지 마라. 정확히 추출한 날짜와 해석 후보를 분리하라. 정확한 원문 발췌를 보존하고 취소 사례도 추가하라. 취소가 기존 일정의 자동 삭제를 허용하는 것은 아니며 사용자 확인이 필요하다.
4. 날짜 파서는 최소 수정으로 정상 ISO 입력 호환성을 유지하고 잘못된 offset 분 및 혼합 구분자를 거부하라. `20260923`, `2026-09-23T15:00:00+0900`은 기존 정상 입력이다. 점 구분 날짜, 소수초, +09:00, Z, 없는 날짜, garbage, +09:99/-00:60 등 경계를 검사하라. 지원 형식과 시간대 미지정 UTC 정책을 문서화하라. 단순히 datetime.fromisoformat에 위임하면 일부 잘못된 offset도 정상화될 수 있으니 사전 검증을 고려하라.
5. 저장 계약에 날짜-only를 손실 없이 표현하는 date 필드와 확정 datetime 필드 및 시간대를 정의하라. 종일/날짜-only 마감/시각 확정/부분 정보 후보의 차이를 설명하고 필드 조합 제약과 JSON 예시를 적어라. 미확정 후보와 확정 저장 모델을 분리하라. 실제 모델/API/DB는 만들지 마라.
6. 평가 상태 보고 정의와 이전 보고의 과장/부정확한 표현을 새 수정 보고서에서 정정하라. mock, live, 미호출 유보, 실패, 미실행, 판정 대기를 구분하고 분모와 지연 집계 대상을 명시하라. 기존 평가기 자체를 수정하지 마라.

## 검증

- 날짜 파서의 신규 경계값과 기존 정상 형식의 회귀 테스트를 추가하라.
- fixture 검증은 모든 후보 확인 필수, 모호한 timestamp 비확정, 날짜/시각 형식, 후보 수, 고유 ID, 원문 발췌의 실제 포함 여부를 검사하라. 날짜별 의미를 테스트로 자동 증명했다고 주장하지 마라.
- 실제 금액·자격 등은 원문을 사람이 대조할 수 있도록 근거를 남겨라. 코드 테스트 성공만으로 정답표 검수가 끝났다고 하지 마라.
- 다음 4개 파일 및 필요한 추가 테스트를 `.venv/bin/python`으로 실행하라:

```bash
.venv/bin/python -m pytest tests/test_codex_round2_fixes.py tests/test_codex_fixes.py tests/test_retrieval_grounding.py tests/test_date_parsing.py -q
```

수정 범위는 기존 날짜 파서·관련 테스트·평가 문서/fixture·수정 보고서다. 운영 DB 및 원시 JSON 변경, 실 API 호출, 재수집, 배포, commit/push, R1 신규 기능 구현은 하지 마라.

`docs/gemini_round0_revision_report.md`에 각 지적별 수정 내용, 변경 파일, 재현/회귀 명령과 실제 결과, 미검증 사항을 기록하라. 원래 보고서의 과거 실행 기록은 새 실행 결과로 덮어쓰지 말고 새 보고서에서 정정하라. 완료 후 Codex 재검수를 기다려라.

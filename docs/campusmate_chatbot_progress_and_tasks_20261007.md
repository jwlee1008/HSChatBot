# CampusMate 챗봇 진행 상황과 남은 과제

기준일: 2026년 10월 7일

CampusMate는 **로그인 없이 한성대학교 공식 공지와 학사 안내를 질문하고, 답변과 공식 원문을 확인하는 챗봇**으로 정리한다. 현재 작업 폴더에서는 챗봇 전용 코드 분리와 PRD 개정이 이미 완료돼 있다. 개발 단계는 **챗봇 MVP 구현과 선별 회귀 검증 완료, 최신 데이터와 실제 답변 품질 및 운영 배포 검증 진행 전**으로 판단한다.

10월 7일 후속 작업으로 **P0 산출물 통일을 완료했다.** 현재 제출·발표 기준은 [챗봇 산출물 묶음](chatbot_release_20261007/README.md)의 PRD v1.2, 수행 계획서, 발표자료, 마일스톤, WBS와 대본이다. 기존 자료는 이전 버전으로 보존한다. 현재 Gemini 설정과 데이터 반영 연결 및 Cloudtype 무료 환경 조사는 [추가 계획](campusmate_data_and_cloudtype_plan_20261007.md)을 따른다.

전체 진척률을 임의의 백분율로 제시하지 않는다. 기존 WBS의 완료 비율은 과거 기획 시점 값이며, 현재 기능·평가·배포 상태를 반영한 계산이 아니다.

## 현재 제품 범위

- 대상: 학사·장학·졸업·휴복학·시설 등 학교 정보를 찾는 재학생과 신입생.
- 핵심 흐름: 질문 입력 → 공식 근거 검색 → 답변과 출처 카드 확인 → 공식 원문 확인.
- 유지 기능: 자연어 질문, 공식 공지·안내 검색, 대상·기간·조건 요약, 제목·게시일·원문 링크 표시, 근거 부족·본문 미확보·API 오류 안내.
- 현재 대화 방식: 질문별 독립 검색·답변. 화면에는 이전 메시지가 남지만 서버에 대화 이력을 보내지는 않는다.
- 활성 범위에서 제외: 회원가입·로그인, 개인 일정 CRUD, 일정 후보 확인·저장, 캘린더, 마감 알림, 외부 캘린더 동기화.
- 기존 개인 일정 구현은 `archived_features/personal_schedule_20260927/`에 보관한다. 개인 일정 DB의 PostgreSQL 이식은 현재 챗봇 출시 과제가 아니다.

오늘 재실행한 검사 파일은 `test_chatbot_only.py`, `test_codex_round2_fixes.py`, `test_codex_fixes.py`, `test_retrieval_grounding.py`, `test_date_parsing.py`다. 외부 API 호출과 모델 다운로드 없이 실행했다. 개인 계정 SQLite 연결을 금지한 상태에서도 서버 기동과 익명 질의 계약을 확인하는 검사가 포함된다.

9월 27일 보고서에는 React 빌드 성공, 모바일 390×844 화면의 질문·답변·원문 링크 흐름, 로컬 평가 근거 대조 10/10, 보관 파일 34개 해시 확인도 기록돼 있다. 당시 모바일 답변은 mock이며, 이 기록을 오늘 실제 모델·브라우저 검증 결과로 바꾸어 설명하지 않는다.

## 데이터와 답변 품질의 현재 한계

현재 통합 데이터는 공지 986건, 상시 안내 144건, FAQ 179건, 서식 57건으로 구성된다. 본문·혼합·OCR 상태는 1,164건이고 제목만 확보한 문서는 202건으로 전체의 약 14.8%다. 본문 확보 상태가 곧 추출 내용의 완전성이나 OCR 정확도를 뜻하지는 않는다.

통합 JSON의 최신 게시일과 최근 확인 시각은 2026년 9월 15일까지다. 기준일인 10월 7일과 22일 차이가 있으므로 최신 공지와 변경 규정을 갱신할 필요가 있다. 현재 기본 DB는 통합 JSON과 문서 ID·내용 해시가 맞고 3,447청크를 가진다. 로컬 파일 간 정합성과 학교 원문의 최신성은 별도로 관리해야 한다.

정기 크롤링과 공식 안내 갱신 워크플로는 이미 있다. 다만 수집 결과가 통합·재색인·실행 서버 반영까지 자동으로 연결된 상태는 아니다. 최신 원격 워크플로 실행 여부는 이번에 확인하지 않았다.

| 평가 기록 | 확인된 결과 | 현재판에 적용할 수 있는 해석 |
|---|---|---|
| 9월 14일 로컬 Qwen 20문항 | 자동 판정 16/20, 수동 원문 대조 15/20 | 당시 모델·코드·자료의 결과. 현재판 정답률로 사용하지 않음 |
| 9월 15일 Gemini 확장 10문항 | PASS 1, API_ERROR 9 | 오류가 많아 전체 답변 품질 평가 미완료 |
| 9월 15일 핵심 5문항 | API_ERROR 1, NOT_RUN 4, 생성 성공 0 | 저장된 핵심 실제 API 평가도 미완료 |
| 9월 27일 분리 검증 | 선별 검사 65개, 평가 근거 대조 10/10, 모바일 mock 흐름 | 코드·근거·화면 확인. 답변 정확도 100%를 의미하지 않음 |
| 10월 7일 재검사 | 선별 검사 65개 통과 | 현재 작업 폴더의 회귀 동작 확인 |

특히 TOPCIT의 여러 신청 단계와 날짜를 함께 회수하지 못한 사례, 제목과 본문의 기간 충돌, 다른 공지의 대상 조건이 함께 검색된 사례가 있다. 핵심 조건·제외 대상·날짜가 한 답변에서 섞이지 않는지 실제 생성 결과를 검수해야 한다. OCR로 마감 시각이 잘못 읽힌 사례도 원문 이미지 대조가 필요하다.

WBS의 착수 70%·Sprint 1 19%는 현재 실제 진척을 계산한 값으로 볼 수 없다. 일부 요약 셀은 AI 함수를 감싼 과거 대체 문자열이며, 이미 구현된 검색·API·웹 항목도 0%로 남아 있다. WBS의 10월 17일 종료 계획과 마일스톤 PPT의 15주차 계획도 제출 일정에 맞춰 통일해야 한다.

Word·PPT·WBS 원본은 보존하고 최신 챗봇 개정본을 별도 작성했다. 위 표의 정리 항목은 새 산출물에 반영했으며, 이제 [최신 산출물 목록](chatbot_release_20261007/README.md)을 기준으로 사용한다. 루트의 발표 대본 세 파일도 챗봇으로 갱신하고 이전 내용은 보관했다.

배포 모델은 설정 분기가 존재하는 것과 실제 실행 가능한 것을 구분한다. 예를 들어 OpenAI를 선택한다면 현재 코드가 사용하는 `langchain_openai`의 의존성 선언을 보완해야 한다. 실제 모델과 배포 대상이 정해지면 해당 경로를 먼저 검증한다.

## 권장 진행 순서

1. **데이터와 담당 확정:** 통일한 PRD v1.2와 WBS를 기준으로 실명 담당·제출 기한을 확정하고 최신 공지와 대표 평가 질문을 준비한다. 수집 파일을 통합 입력에 연결하고 새 색인을 검증한다.
2. **실제 답변 평가와 개선:** 검색 근거와 실제 LLM 답변을 함께 기록하고, 날짜·대상·제외 조건 오류부터 수정한다. 응답시간은 검색·생성·전체, 최초·반복 요청을 구분해 측정한다.
3. **검증용 배포와 사용자 테스트:** 최신 이미지를 목표 환경에서 실행하고 학생에게 질문·출처 확인 흐름을 테스트한다. 이 단계에서 메모리·동시 요청·통신 오류도 확인한다.
4. **운영 반영과 제출 마무리:** 자료 갱신·복구 방법을 확정하고 실제 측정값을 최종 PPT·기술보고서·README·시연 자료에 반영한다.

BM25, 카카오톡 연동, 로컬 모델 추가 운영, 다회차 대화, 전 게시판 전수 수집은 핵심 평가와 배포를 끝낸 뒤 선택할 확장 과제다. 개인 일정·캘린더·알림을 챗봇 완성의 선행 조건으로 다시 넣지 않는다.

## 성공 기준과 발표 시 표현

최신 PRD의 목표는 대표 질문 30개 이상, 근거가 핵심 사실을 지지하는 답변 90% 이상, 사용자 10명 이상, 만족도 4.0/5 이상이다. 모두 **앞으로 검증할 목표**이며 달성 실적이 아니다. 범위 밖·근거 부족·본문 미확보 질문의 적절한 유보도 별도 판정한다.

기존 계획의 3초 응답 목표를 유지하려면 어떤 모델·환경에서 최초 요청인지 반복 요청인지, 전체 응답의 p95인지 등을 먼저 정한다. API 오류의 빠른 반환과 미실행 0초를 정상 생성 속도에 섞지 않는다.

발표에서는 다음처럼 설명할 수 있다.

> CampusMate는 한성대학교의 분산된 공식 공지와 학사 정보를 검색하고, 근거를 바탕으로 답변과 원문 링크를 제공하는 챗봇입니다. 현재 1,366문서와 3,447청크의 검색 기반, 웹과 API, 근거 부족 및 오류 처리를 구현했고 핵심 회귀 검사 65개를 통과했습니다. 앞으로 최신 자료를 갱신하고 실제 모델의 답변 정확도와 응답시간을 평가한 뒤, 최신 챗봇판 배포와 학생 사용자 테스트를 진행합니다.

최신 챗봇판의 외부 배포 완료는 확인되지 않았다. 마지막 Cloudtype 점검 기록은 9월 26일의 관찰값이므로 오늘 운영 상태로 단정하지 않는다. 이번 점검은 로컬 파일·데이터·코드와 선별 회귀 검사에 한정했고, 외부 모델 호출·재크롤링·배포·commit/push는 수행하지 않았다. 챗봇 변경과 여러 문서가 작업 폴더의 미커밋 변경으로 남아 있으므로 릴리스할 변경 묶음과 버전 정리도 필요하다.

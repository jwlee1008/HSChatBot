# 배포 준비 후속 검수 — 2026-09-26

Gemini 중단 작업을 Codex가 이어받아 검수했다. 범위는 로컬 Linux ARM64 컨테이너의 재현성, 인증·일정 API, 데이터 영속성 및 백업 복원이다. 공개 배포 완료 판정이 아니다.

## 중단 원인과 수정

이전 Docker 빌드는 base image metadata 단계에 수 시간 머물렀다. 해당 빌드를 중단하고 재빌드했다. 로그로 확인되는 정체 지점은 metadata이며 네트워크/레지스트리/빌더 중 어느 요소가 근본 원인인지는 확정하지 않았다.

- Dockerfile의 Node 22 및 Python 3.12 기본 이미지를 실제 사용한 digest로 고정했다.
- requirements-lock.txt의 Linux ARM64 검증 범위를 명시했다. macOS torch는 `>=2.5.0`이므로 완전한 macOS 잠금이 아니다. AMD64 빌드도 미검증이다.
- 컨테이너 API 검사 스크립트의 잘못된 성공 코드, PATCH confirmed 계약, UTC 응답값, snapshot 함수 호출을 실제 API 계약에 맞췄다. TestClient lifespan을 실행한다.
- Gemini 보고서의 실제 공지 검사명/날짜를 실행 결과로 정정했다. `/health`는 DB 상태를 직접 검사하지 않으며, 현재 인증에는 JWT 시크릿 설정이 없다는 점도 반영했다.

## 남은 운영 결정

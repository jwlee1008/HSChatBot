## 자료의 기준과 한계

TRD·프로그램 목록·StoryBoard의 기능 기준은 `8349320`에 당시 로컬 런타임·지식 갱신 작업을 더한 상태입니다. 관련 로컬 변경을 모두 원격 `main`에 통합한 상태와는 구분합니다. 표의 ‘구현’은 코드 존재 기준이며 실제 LLM 품질·운영 적용 완료를 뜻하지 않습니다.

TRD에 기록한 1,485문서·6,886청크와 제목만 있는 문서 3개는 10월 9일 로컬 확장 기록입니다. 원격 Git 기본 seed는 1,366문서·3,447청크입니다. 운영 서버에 확장 DB가 적용됐는지는 이번 문서 작업에서 검증하지 않았습니다.

10월 18일 앞서 실행한 선별 오프라인 검사는 57통과·1실패·경고 1건입니다. 실패는 prewarm 비활성 조건에서 `/health`의 `doc_count`가 0인데 테스트가 1 이상을 기대하는 사례이며 TRD에 원인과 범위를 기록했습니다. 실제 생성 답변의 정확도와 구분합니다.

실명별 담당자와 종료일·제출 기한은 미확정으로 표시했습니다. 화면 UI-014는 500자 입력 사전 안내의 개선 설계이며 현재 구현으로 표기하지 않습니다.

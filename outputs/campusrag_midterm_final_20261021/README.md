v2: 개발 과정의 특정 날짜를 빼고 사용자 확인 흐름인 Qwen 사용, Cloudtype 무료 배포 용량 부족, Gemini API 대체, 홈서버 이전을 반영했다. 대본과 PPT 발표자 노트에서 검정은 읽는 멘트, 파랑은 진행 메모·조작·시간 등 읽지 않는 안내로 구분했다. 색상 외에도 메모와 조작 표기를 유지했다.

PPT 발표자 노트와 대본의 장 순서·내용·시간을 맞췄다. Word 대본 끝에 예상 질문 12개를 배치했다. 데이터 규모·세부 검증 수치는 예상 질문에서 확인한다. 이름 네 칸은 공란으로 유지했다.

운영 근거는 [홈서버 조사](../../docs/campusrag_home_server_presentation_audit_20261021.md)와 [원시 검증](../campusrag_home_server_audit_20261021/validation.json)을 사용했다. 과거 평가·목표와 현재 실측을 구분했다.

시연 주소는 https://hschatbot.jwlee.dev 이다. 행사 질문은 2026-10-22 행복米밥차 공지를 기준으로 검증했다. 발표 당일 공식 원문을 다시 확인하며, 행사 이후에는 과거 일정 질문으로 명시하거나 새 질문을 검증한다. PWA 설치는 미검증이므로 실제 시연은 웹으로 구성했다.

리허설은 실제 발화·전환·생성 대기를 포함한다. 설명 7분 배분은 계획 시간이며 실제 발화 시간은 리허설로 조정한다. 장애 시 [기존 실제 FAQ 화면](../campusrag_home_server_audit_20261021/campusrag-web-faq.png)으로 전환하고 캡처 사용을 밝힌다.
